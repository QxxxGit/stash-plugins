# Qx File Browser

Browse your files within Stash!

> NOTE! This is an early test build. It is currently in READ-ONLY mode, meaning no changes can be made to your files.

## Features

* View all your scanned files and folders of your library.
* View recently added files and folders.
* Custom context menus (right click on files for additional functionality).
* Lightbox supported to preview your images inside a folder.
* Double clicking a file takes you to the Stash page for the file.
